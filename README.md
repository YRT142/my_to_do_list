# Simple To-Do List App

A clean, responsive, and lightweight single-page To-Do List application built using HTML, CSS, and Vanilla JavaScript.

## Features
- **Add Tasks:** Easily add new items to your daily checklist.
- **Toggle Completion:** Click on any task text to mark it as completed (styled with grey color and a line-through) or uncompleted.
- **Delete Tasks:** Remove items you no longer need using the delete button.
- **Live Counter:** Automatically tracks how many tasks are remaining out of the total.
